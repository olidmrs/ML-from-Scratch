# Learning-ML

### __Description__

Built multiple supervised and unsupervised machine learning models from scratch (only with numpy).

__Supervised learning:__

- Linear Regression **'supervisedlearning/linearregression.py'**
- Logistic Regression
- Neural Network (for multiclass and binary classification problems. Regression problems to be instaured)

__Unsupervised learning:__

- K means clustering
- DBSCAN clustering


### __Motivation__

I started this project to get a better understand of different Machine Learning models typically used in Data science. The goal was to get a better understanding of the foundation of these ML models and not to optimize the performance. Pratically no feature engineering was done as it wasn't the objective of this project

### __Organisation__

**'modelapplications.ipynb'**:
Used to apply all these models to real data sets

**'supervisedlearning/linearregression.py'**:
Used to design the linear regression model
