# Learning-ML

### __Description__

Built multiple supervised and unsupervised machine learning models from scratch (using only NumPy).
**'modelapplications.ipynb'** is used to see these models applied to different datasets.

__Supervised learning:__

- Linear Regression **'supervisedlearning/linearregression.py'**
- Logistic Regression **'supervisedlearning/logisticregression.py'**
- Neural Network: For multiclass and binary classification problems (regression functionality to be implemented)
  **'supervisedlearning/neuralnetwork.py'**

__Unsupervised learning:__

- K means clustering **'unsupervisedlearning/dbscan.py'**
- DBSCAN clustering **'unsupervisedlearning/kmeans.py'**


### __Motivation__

I started this project to get a better understand of different machine learning models commonly used in data science. The goal was to focus on the foundational principles of these ML models rather than optimizing their performance. Pratically no feature engineering was done, as it wasn't the objective of this project.
